# XiaoJuClaw 用户使用手册

> 本文件是检索与维护用的文字参考，不是客户主手册。正式图文操作手册位于 `web/public/user-guide/index.html`，应用内点击“使用手册”或 USB 根目录的 `XiaoJuClaw-User-Guide\index.html` 即可打开。
>
> 适用版本：XiaoJuClaw 1.2.2  
> 适用形态：Windows 安装版、U 盘便携版、离线版  
> 最后更新：2026-07-11

XiaoJuClaw 是面向“一人公司”和小团队的本地数字员工平台。它可以协助聊天问答、内容创作、知识库检索、工作流执行、定时任务、渠道回复和虚拟商品卡密管理，但不会替代经营者对付款、退款、发布、删除和账号风控等高风险动作的最终判断。

如果你第一次使用，先完成“10 分钟快速上手”，不要一开始就配置全部功能。

## 1. 10 分钟快速上手

### 第 1 步：启动软件

- 安装版：从桌面快捷方式或开始菜单打开 `XiaoJuClaw`。
- U 盘便携版：先解压或完整复制交付文件夹，再双击 `Start-XiaoJuClaw.bat`。也可以打开 `XiaoJuClaw` 文件夹后运行 `XiaoJuClaw.exe`。
- 离线版：启动方式与 U 盘便携版相同。

不要直接在压缩包内运行软件，也不要只复制一个 EXE。便携版必须保留 `XiaoJuClaw`、`XiaoJuClawRuntime` 和 `XiaoJuClaw-User-Guide`；首次运行后还会生成 `XiaoJuClawData` 用户数据目录。

### 第 2 步：登录或进入离线模式

- 线上版：按页面提示输入手机号或邮箱，获取验证码后登录。
- 已有激活码：登录后进入“激活与设备”，输入激活码并确认设备。
- 离线版：不需要云端账号，可直接进入本地功能。
- 云端暂时不可达：页面会提示离线降级。聊天、本地知识库等功能仍可使用，但登录、激活、远程能力更新等云功能暂不可用。

验证码、激活码和模型 API Key 是三类不同凭据，不要混用。

### 第 3 步：配置一个可用模型

1. 点击左下角头像或账号区域。
2. 打开“设置”。
3. 进入“模型”。
4. 选择可用的内置模型，或添加自己的兼容模型。
5. 自带模型通常需要填写接口地址、模型 ID 和 API Key。
6. 保存后进入“聊天”，发送“请回复：配置成功”进行验证。

如果聊天提示 401 或 403，通常是 API Key、接口地址或账号权限错误；提示 429 通常是服务商限流或余额不足。

### 第 4 步：填写经营画像

1. 打开左侧“今日经营”。
2. 填写公司/项目名称、业务类型、产品或服务、目标客户、经营渠道、当前目标和限制条件。
3. 保存后点击“生成经营简报”。

经营画像是后续建议的事实基础。没有填写的信息，数字员工不应自行编造。

### 第 5 步：完成第一个任务

1. 打开“数字员工”。
2. 选择与你当前目标最接近的任务卡。
3. 填写真实资料和明确要求。
4. 点击执行。
5. 如果任务卡带“工作流”标记，执行后会进入工作流详情，可查看每一步状态和产出。

推荐第一次使用“写一封邮件”“生成商品文案”或“生成今日经营简报”等低风险任务。

### 第 6 步：检查结果再使用

重点核对数字、日期、价格、链接、法律表述、承诺条件和外部事实。对外发送、发布商品、付款、退款、删除数据前必须人工确认。

## 2. 认识三种交付形态

### Windows 安装版

- 适合固定电脑长期使用。
- 可从开始菜单启动，可使用安装版更新。
- 用户数据不与安装目录混放。
- 卸载或重装前仍建议先备份数据。

### U 盘便携版

- 适合随身携带、试用或在多台 Windows 电脑上运行。
- 不要求电脑预装开发工具。
- 程序、运行工具和用户数据分成三个目录。
- 不要在两台电脑上同时打开同一个 U 盘中的软件，避免数据库冲突。
- U 盘速度较慢时，可以把整个交付文件夹复制到本机磁盘再运行。

### 离线版

- 不连接 XiaoJuClaw 云端，不提供云端登录、激活、远程能力下发和在线更新。
- 可以使用本地数据和本地工具。
- 如果配置了第三方在线模型、在线搜索、媒体服务或消息渠道，相关数据仍会发送到对应的第三方服务。
- 要实现物理断网使用，需要配置本机可访问的本地模型接口，并避免启用任何联网工具。

### Windows 出现安全提示怎么办

早期便携版可能显示“未知发布者”或 SmartScreen 提示。只使用官方交付介质，并先核对卖方提供的版本号和 SHA-256。来源不明、哈希不一致或被安全软件明确判定为恶意时，不要继续运行，应联系交付方。

不要为了运行 XiaoJuClaw 而关闭 Windows Defender 或其他安全软件。

## 3. 账号、激活与积分

### 登录

线上版采用“账号 + 验证码”登录。验证码有有效期和发送频率限制，连续输错后可能需要等待再试。

收不到验证码时依次检查：

1. 手机号或邮箱是否输入正确。
2. 垃圾邮件、拦截短信或企业邮箱隔离区。
3. 倒计时结束后再点重新发送。
4. 网络是否可访问云端。
5. 仍未收到时记录时间和账号脱敏信息，联系售后。

### 激活

激活码用于解锁相应套餐或线上数字员工权益。激活前请确认：

- 当前登录的是准备长期使用的账号。
- 当前设备是要绑定的设备。
- 套餐名称、有效期和权益与购买说明一致。

续费、升级和积分包不是同一种商品。页面显示的实际套餐和有效期为准，不要根据旧截图判断权益。

### 自带模型 Key

自带 Key 是你与模型服务商之间的凭据。是否收费、限流、保留数据，由该服务商的规则决定。XiaoJuClaw 的激活状态不会自动为第三方 Key 充值。

## 4. 模型、语音和媒体设置

### 配置聊天模型

进入“左下角账号区域 → 设置 → 模型”。

添加自定义模型时通常需要：

- 名称：便于你区分，例如“日常写作”或“本地模型”。
- 接口地址：服务商提供的兼容 API 地址。
- 模型 ID：必须与服务商文档一致。
- API Key：服务商颁发的密钥。
- 其他参数：只有在服务商明确要求时修改。

保存后先用一条短消息测试，再执行长文档或工作流。

### 选择模型的建议

- 日常问答和改写：优先选择速度快、成本低的模型。
- 长文档、复杂分析和工作流：选择上下文更长、工具调用更稳定的模型。
- 图片理解：必须选择支持视觉输入的模型。
- 敏感资料：优先选择可信的本地模型或明确承诺数据保护的服务商。

### 配置语音、图片和视频

进入“设置 → 语音与媒体”。语音识别、语音合成、图片生成和视频生成可能使用不同服务商，需要分别保存和测试。

常见问题：

- 聊天模型可用不代表生图模型可用。
- 服务商支持的模型名称、文件格式和大小上限可能不同。
- 图片或视频生成一般按次计费，执行前先确认服务商余额。
- 生成内容仍需检查版权、肖像、商标和平台规则。

### API Key 如何保存

API Key 保存在当前设备的本地用户数据目录中，当前不是系统级加密保险箱。不要把用户数据目录发送给别人，不要在公共电脑上长期保存生产 Key，离开设备前应删除 Key 或带走整个便携目录。

## 5. 今日经营：一人公司的每日入口

“今日经营”用于把分散功能收口为每天可执行的经营动作。

### 经营画像

建议填写：

- 你在卖什么产品或服务。
- 目标客户是谁。
- 当前主要渠道。
- 本月最重要的目标。
- 时间、预算、库存、人员或合规限制。

资料变化后及时更新。画像越真实，建议越可执行。

### 状态卡片

页面会汇总本地可获得的状态，例如：

- 今日工作流成功、运行中和失败数量。
- 已启用的自动化任务。
- 连续失败的任务。
- 尚未完成的执行计划。
- 已知的模型调用和 Token 使用情况。

部分第三方模型可能不返回完整用量，因此费用数字只能代表已记录部分，不应当作账单。

### 经营简报

点击“生成经营简报”后，系统会使用经营画像和本地运行状态生成行动建议。建议先完成最重要的三件事，再扩展其他任务。

如果简报出现不真实信息：

1. 检查经营画像是否缺字段。
2. 在聊天中明确指出错误事实和正确版本。
3. 要求数字员工“只使用画像和已提供资料，不确定时标注待确认”。

## 6. 数字员工与任务卡

### 数字员工页面

“数字员工”页面是按业务场景整理的任务工作台。办公、电商、内容、财务、人事、客服、研究和闲鱼等分类中的卡片，代表可直接执行的任务入口。

使用步骤：

1. 选择业务分类。
2. 打开任务卡。
3. 填写输入表单。
4. 检查使用的员工和任务说明。
5. 执行并等待结果。

任务卡不会自动知道你电脑外部的数据。订单、商品、客户、价格和政策等资料必须通过表单、附件、知识库或已授权工具提供。

### 工作流任务卡

带“工作流”标记的任务不是一次回答，而是多步骤执行。执行后可以查看每个步骤的状态、耗时和产出；失败时，在问题解决后使用“续跑”，已完成步骤通常不会重复执行。

### Agents 页面

“Agents”用于管理数字员工本身，包括人设、模型和技能。

创建自定义员工时：

1. 写清岗位和目标，例如“负责女装店商品标题、卖点和售后话术”。
2. 使用“AI 优化”把简单描述整理成人设。
3. 检查建议的员工名称和技能，不要无条件接受。
4. 选择模型；未单独选择时通常跟随全局模型。
5. 保存后先做一个小任务测试。

不要把不同业务的全部权限集中给一个员工。涉及财务、删除、发货和外部发布时，应使用职责清晰的专用员工。

## 7. 聊天：如何让数字员工真正做事

### 一个好请求应包含什么

建议按以下顺序说明：

1. 目标：最终要得到什么。
2. 背景：业务、客户和使用场景。
3. 输入：原始资料、附件或链接。
4. 约束：字数、语气、预算、截止时间、禁止事项。
5. 输出格式：清单、表格、邮件、脚本或文件。
6. 验收标准：怎样算完成。

示例：

> 请用办公助理整理附件中的会议记录。输出：决策、负责人、截止日期、待确认问题四部分。不要补写记录里没有的人名和日期；不确定项标注“待确认”。

### 附件

在输入框添加文件或图片后，再说明希望如何处理。图片理解需要视觉模型；录音转写需要先配置语音识别；超大文件建议拆分或放入知识库。

### 多步骤任务

对于需要 3 步以上的任务，可以明确要求：

> 先建立执行计划，再逐步完成。每完成一步更新状态；遇到需要付款、发布、删除或登录验证时暂停并询问我。

执行过程中可停止当前生成。停止后先检查已经产生的文件或外部动作，再决定重试。

### 反馈与记忆

- 结果有用时可以点赞。
- 结果有问题时点踩并填写原因，具体原因比“效果不好”更有价值。
- 要求长期记住时，明确说“请记住：……”。
- 纠正旧信息时，明确给出正确版本，例如“请记住，标准报价已改为 299 元，以前的 199 元作废”。

密码、验证码、完整银行卡号和不需要长期保存的密钥不要写入长期记忆。

## 8. 知识库

知识库适合保存产品手册、制度、报价说明、FAQ 和项目资料，让回答能够基于文档并给出来源。

### 上传资料

1. 打开“知识库”。
2. 点击上传或把文件拖入页面。
3. 支持 `txt`、`md`、`pdf`、`docx`。
4. 等待文件完成解析。
5. 使用页面搜索先验证关键词是否能找到。

扫描图片型 PDF 可能没有可提取文字。当前版本不应假设所有扫描件都能自动 OCR，遇到此类文件请先转换为可复制文本。

### 提问方法

在聊天中选择合适员工，并说明：

> 只根据知识库回答，并列出引用来源。知识库没有答案时直接说没有找到，不要猜测。

### 更新资料

同一制度更新时，先确认旧版本是否仍需保留。多个互相冲突的版本会导致答案不稳定，建议在文件名中加入日期或版本号。

## 9. 工作流

工作流用于把重复业务拆成可查看、可恢复的多步骤流程。

### 运行

1. 打开“工作流”。
2. 选择一个流程。
3. 点击运行。
4. 填写流程要求的输入。
5. 提交后查看运行历史。

### 状态说明

- 运行中：仍有步骤正在执行。
- 成功：全部必要步骤完成。
- 失败：至少一个步骤出错。
- 已跳过：条件不满足，该步骤未执行。

### 失败续跑

1. 打开失败运行。
2. 查看失败步骤和错误信息。
3. 先修复模型、网络、输入、库存或权限问题。
4. 点击“续跑”。

工作流定义在运行开始后如果被修改，为避免产出混乱，旧运行可能不能继续，应重新发起一次。

### 使用建议

- 先用少量真实数据验证，再处理批量任务。
- 循环输入不要一次塞入过多项目。
- 任何涉及外部发布、付款、退款或删除的步骤都应保留人工审核点。
- 工作流运行依赖本机程序和模型服务，不要在执行中强制关机。

## 10. 定时任务

定时任务可让指定员工按计划执行提示词，并可把结果推送到已配置渠道。

### 新建任务

1. 打开“定时任务”。
2. 点击新增。
3. 填写任务名称。
4. 选择数字员工。
5. 写清要执行的内容和输出格式。
6. 选择执行方式：
   - 间隔：每隔若干分钟、小时或天执行。
   - 日/周/月计划：使用可视化时间设置。
   - 单次：在指定时间执行一次。
7. 如需推送，选择已配置的渠道和会话。
8. 保存并确认任务处于启用状态。

### 重要限制

- 调度器运行在本机，计划时间到达时 XiaoJuClaw 必须正在运行。
- 电脑休眠、关机、断网或模型不可用时，任务可能失败或延迟。
- 发送附件时，附件必须位于当前员工允许的工作区内。
- 先设置一次 5 分钟后的单次任务验证，再创建长期任务。

### 排查失败

打开任务运行记录和“日志”，检查模型、网络、渠道、文件路径和权限。连续失败的任务应先停用，避免重复消耗。

## 11. 渠道与浏览器

### 消息渠道

进入“设置 → 渠道”配置 Telegram、飞书、QQ、企业微信、钉钉、微信公众号或个人微信等渠道。不同平台所需凭据和回调配置不同，以设置页提示和对应平台后台为准。

上线前建议：

1. 使用测试群或测试账号。
2. 先验证收消息。
3. 再验证发文字。
4. 最后验证图片和文件。
5. 确认群聊中哪些人有权触发数字员工。

渠道平台的权限、限流和风控规则优先于 XiaoJuClaw。不要使用自动化绕过验证码、二次验证或平台限制。

### 浏览器

浏览器功能用于打开公开网页或在你已授权的浏览器资料中辅助操作。

- 首次登录、扫码、验证码和风控确认应由人工完成。
- 不要让数字员工规避滑块、验证码或账号安全验证。
- 涉及上架、改价、发货、退款和删除时，应先小范围验证并保留人工确认。
- 浏览器自动化不是平台官方接口的替代品，页面改版后可能失效。

## 12. 技能、记忆与悬浮提醒

### 技能

技能是数字员工的专用工作说明或工具能力。

- 在“技能”页面查看已安装和启用状态。
- 安装第三方技能前检查来源、权限和说明。
- 技能越多不代表效果越好，只给员工启用岗位真正需要的技能。
- 安装后先用非敏感数据测试。

数字员工也可以在聊天中自查技能、发现推荐技能，并在获得你同意后安装允许来源的技能。

### 记忆

“记忆”页面用于查看长期事实和近期记录。过期价格、旧联系人和错误偏好应及时纠正或删除。

不同数字员工有各自工作区和记忆，不要假设一个员工自动知道另一个员工的全部资料。

### 悬浮提醒窗

桌面版可以从侧边栏打开悬浮提醒窗。长任务在后台完成后，悬浮窗会提示结果；点击提示可回到对应聊天。悬浮窗只是提醒，不代表结果已经人工验收。

## 13. 卡密库与闲鱼客服

“卡密库”用于本地管理虚拟商品 SKU、卡密库存和发货台账。

### 准备库存

1. 打开“卡密库”。
2. 新建 SKU，并填写能与商品对应的编码和名称。
3. 批量导入卡密，通常每行一条。
4. 检查可用库存数量。
5. 使用少量测试卡验证流程。

### 辅助发货

在聊天中使用“闲鱼客服”员工，并提供唯一订单号和正确 SKU。系统会按订单号做幂等控制，避免同一订单重复领取不同卡密；发货台账默认打码显示。

### 当前能力边界

当前版本是“本地库存 + 辅助发货”，不是闲鱼平台无人值守全托管：

- 不会自动感知真实闲鱼订单。
- 不会自动读取或发送闲鱼聊天消息。
- 不会绕过登录验证或平台风控。
- 卖家仍需核对订单号、SKU 和买家状态，并把交付内容发送到平台。
- 退款、纠纷、实物物流和高风险售后必须人工处理。

卡密需要用于生成交付内容时，可能进入所选模型的处理上下文。请使用可信模型服务，禁止在截图、日志或售后材料中暴露完整卡密。

## 15. 数据备份、恢复与升级

### 便携版目录说明

- `XiaoJuClaw`：程序文件，升级时可替换。
- `XiaoJuClawRuntime`：随包工具，升级时可替换。
- `XiaoJuClaw-User-Guide`：独立图文手册，完整包升级时应同步替换。
- `XiaoJuClawData`：数据库、设置、Key、聊天、知识库、任务和员工工作区，绝不能被升级包覆盖或删除。

### 正确备份

1. 等待所有聊天、工作流和任务结束。
2. 完全退出 XiaoJuClaw，包括悬浮提醒窗。
3. 确认任务管理器中没有 `XiaoJuClaw.exe` 和 `XiaoJuClaw-server.exe`。
4. 便携版复制整个 `XiaoJuClawData` 目录。
5. 安装版在“设置 → 环境”查看实际用户数据路径，再复制整个目录。
6. 把备份保存到另一块磁盘，并标注日期和版本。

不要在软件运行时只复制 `XiaoJuClaw.db`。数据库可能同时使用 `-wal` 和 `-shm` 文件，单独复制会得到不完整备份。

### 恢复

1. 完全退出软件。
2. 先把当前数据目录改名保留。
3. 把完整备份放回原路径。
4. 启动软件，检查设置、聊天、知识库、任务和工作区。
5. 验证成功后再决定是否删除旧目录。

不要把不可信来源的用户数据目录恢复到生产电脑。

### 便携版升级

- 软件内提示热更新时，按提示退出并更新，不要中途拔出 U 盘或强制关机。
- 获取完整新包时，替换 `XiaoJuClaw`、`XiaoJuClawRuntime` 和 `XiaoJuClaw-User-Guide`，保留原来的 `XiaoJuClawData`。
- 从旧扁平目录升级时，合并复制新包后只运行一次 `Migrate-Legacy-Layout.bat`。
- 更新失败时不要手工删除数据目录，先保留失败提示和日志并联系售后。

### 安装版升级

使用应用内正式更新或官方安装包覆盖安装。升级前做一次数据备份；版本回退可能不兼容新版数据库，不建议直接安装更低版本，应优先等待更高版本的修复包。

### 云盘和同步软件

不要在 XiaoJuClaw 运行时让多个设备同时同步同一个活动数据目录。需要云备份时，先退出软件，再同步备份副本。

## 16. 常见问题排查

### 软件打不开或立即退出

1. 确认不是在压缩包内运行。
2. 便携版确认两个程序目录完整。
3. 重新运行 `Start-XiaoJuClaw.bat`。
4. 检查磁盘空间、U 盘只读状态和安全软件隔离记录。
5. 重启电脑后再试。
6. 仍失败时提供版本、时间和日志，不要反复删除数据目录。

### 页面一直显示启动中

等待 30 秒后查看是否出现端口冲突或 sidecar 恢复提示。关闭重复启动的 XiaoJuClaw，再重试；不要同时打开同一个数据目录的多个实例。

### 聊天没有回复

依次检查：

1. 模型是否已配置并选中。
2. API Key、接口地址和模型 ID。
3. 服务商余额与限流。
4. 网络和代理。
5. “日志”中的 401、403、429、超时或模型不支持工具等信息。

### 登录后又回到登录页

检查系统时间是否正确、云端是否可达、验证码是否过期。云端故障导致的离线降级与 401 鉴权失败不是同一问题；如果明确提示登录失效，请重新登录。

### 工作流长时间运行

打开运行详情看具体步骤。模型或工具有超时保护，但排队、网络慢和服务商限流仍会延长时间。不要连续重复点击运行，否则可能产生多次模型费用。

### 定时任务没有执行

确认软件在计划时间处于运行状态、电脑未休眠、任务已启用、时间和时区正确。先创建一个 5 分钟后的单次任务验证。

### 知识库搜不到内容

确认文件格式受支持且解析完成；用原文中的独特关键词搜索。扫描 PDF 需要先 OCR，图片中的文字不会自动保证可检索。

### 渠道能收不能发

检查机器人发送权限、会话 ID、平台限流、文件大小和媒体类型。先测试纯文字，再测试文件。

### U 盘更新后数据不见了

不要继续写入或新建大量数据。检查原目录中的 `XiaoJuClawData` 是否仍存在，以及是否误从新包的另一个位置启动。保留原 U 盘，不要格式化，联系售后协助定位。

## 17. 安全和合规边界

以下动作默认应由人确认：

- 付款、退款、转账、开票和财务入账。
- 商品上架、下架、改价、库存清零和批量发布。
- 向客户作出价格、赔偿、时效、法律或售后承诺。
- 删除文件、知识库、员工、工作流、库存或聊天。
- 登录验证、扫码、验证码和平台风控处理。
- 对外发送包含个人信息、商业机密或完整卡密的内容。

使用第三方模型、搜索、媒体和消息渠道时，输入可能离开本机。只提供完成任务所需的最少数据，并遵守客户授权、隐私、版权和平台规则。

XiaoJuClaw 不应被用于批量养号、绕过验证码、多账号规避风控、未授权采集数据或其他违反平台规则的自动化。
