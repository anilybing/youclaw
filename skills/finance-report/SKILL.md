# 财务报表分析（finance-report）

把用户的收支数据，浓缩成一份「一眼看懂经营状况」的简易财务概览 + 可落地的经营建议。计算基于用户真实数据，数据不出本机。

## 工作流

1. **拿到数据**：
   - 用户上传 `.xlsx`/`.csv` 时，配合 office-excel 技能做本地汇总/透视，拿到收入、成本、各类目金额等结果表，不必把原始明细全塞进对话。
   - 用户直接粘贴表格/流水文本时直接解析。
   - 没有数据先向用户要，不凭空开写。
2. **利润概览**：算出——总收入、总成本（可细分主营成本/期间费用）、毛利（收入−成本）、毛利率（毛利/收入）。有多期数据时并列展示各期。
3. **现金流概览**：算出期内现金流入、流出、净现金流；区分经营性收支与一次性大额进出，指出结余是否健康、有无入不敷出。
4. **经营洞察（3~5 条）**：每条 = 发现 + 数字依据 + 建议动作，方向包括：
   - **成本占比**：哪几类成本占比最高、是否偏离常态
   - **异常波动**：某项收入/支出的突增突减及可能原因
   - **环比/同比**：本期 vs 上期的关键变化
5. **产出报告**：默认 Markdown「财务概览」——概览数字（利润/现金流）→ 关键发现 → 经营建议（按优先级排序）。用户要图表可视化时转交 data-report 技能，要正式文档时转 office-doc 技能。
6. **定时小结**：本技能可配合定时任务做月度/周度财务小结——把固定分析口径写进任务 prompt，到点自动读最新数据出概览（结果可推送到指定渠道）。

## 红线

- **不编数字**：报告里每个数字都必须来自用户数据或对其的真实计算；数据不足以支撑某个分析角度时，明确说明「假设」与「局限」（如"缺成本明细，毛利仅按收入−采购估算"），不用假数凑结论，缺口标【需核实】。
- **小样本注明局限**：期数少或时间窗过短时，在显著位置注明"样本有限，结论仅供参考"。
- **数据不出本机**：全程本地计算，收支数据属用户隐私，绝不上传外部服务。
- **不越界给专业结论**：不做税务筹划、投资建议等合规性"结论"；涉及报税、税务处理时一律提示「请以当地税务规定或专业会计意见为准」。
