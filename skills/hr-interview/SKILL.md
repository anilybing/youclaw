# 面试题库（hr-interview）

按岗位与层级生成结构化面试题，每题标注考察维度与评估要点，可选生成面试评分表模板。

## 需要的输入

- **岗位名称/方向**（缺失则先问）
- **层级**：初级 / 中级 / 高级（决定题目深度与占比）
- **关注点**（可选）：某些必考技能、团队文化偏好、要重点考察的软素质
- **数量/时长**（可选）：一场面试大致几道题、多长时间

## 题型与结构（三类）

| 题型 | 目的 | 说明 |
| --- | --- | --- |
| 专业能力题 | 硬技能、方法论、知识深度 | 层级越高越偏架构/权衡/复盘；初级偏基础与实操 |
| 行为面试题（STAR） | 用过往真实行为预测未来表现 | 引导候选人按 情境-任务-行动-结果 展开 |
| 情景题 | 面对假设难题的思路 | 无标准答案，看分析框架与取舍 |

## 每题必带

- **题面**：清晰、单一、开放（避免是非题）
- **考察维度**：这道题在测什么（如"系统设计能力""跨部门协作""抗压能力"）
- **参考评估要点**：好答案会覆盖哪些点 / 有哪些危险信号（是评分锚点，不是唯一标准答案）

## 层级差异（同一岗位）

- **初级**：基础知识、执行力、学习意愿、可培养性
- **中级**：独立负责、方案落地、协作沟通、结果交付
- **高级**：架构/策略、跨团队影响力、带人/决策、复盘与体系化

## 面试评分表模板（用户需要时给）

表格列：**考察维度 / 评分（1~5）/ 观察记录 / 备注**；末尾留总体评价与录用倾向（推荐 / 待定 / 不推荐）。用户要落 Excel 时调用 office-excel 技能。

## 工作流

1. 确认岗位 + 层级（缺失先问）。
2. 按三类题型出题，标注每题考察维度与评估要点；默认三类均衡覆盖，用户可指定偏重。
3. 需要时附上评分表模板。

## 红线

- 面试题**只考察岗位胜任力**，不出涉及**婚育、年龄、性别、宗教、籍贯、健康、政治**等歧视性或隐私性问题；如需了解到岗时间/出差意愿，用中性、与工作相关的问法。
- 参考评估要点是锚点而非唯一答案，提醒面试官结合候选人实际作答判断，避免机械对答案。
