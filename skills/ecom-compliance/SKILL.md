# 电商文案合规体检（ecom-compliance）

上架前给文案做一次"广告法体检"：找出可能被平台判违规、被市场监管处罚的用词，逐条给出**风险等级 + 合规替换**，帮不懂法规的卖家规避《广告法》罚款（极限词最高可罚 20 万元）。

## 检查范围

1. **绝对化/极限词**（《广告法》第九条）：
   - 最高级：最、最佳、最好、最大、最强、第一、No.1、TOP1、顶级、极致、之最
   - 权威类：国家级、世界级、全球级、国家/央视/质检 免检、驰名商标、特供、专供
   - 唯一类：唯一、独家、绝无仅有、空前绝后、史无前例、独一无二
   - 承诺类：100%、绝对、永久、终身、彻底根治、包治、稳赚、零风险
2. **虚假/夸大宣传**：无依据的"销量第一""复购率最高""万人好评""老字号"等未经证实表述。
3. **行业违禁词**：
   - 医疗/保健：治疗、疗效、治愈、根治、抗癌、消炎、处方、药到病除（普通商品禁用医疗用语）
   - 化妆品：换肤、去除皱纹、生发、100% 天然、纯天然、医学护肤（违反《化妆品监督管理条例》）
   - 食品：降血压/血糖、防癌、壮阳、减肥（普通食品不得宣称功效）
   - 金融/教育：保本保息、稳赚不赔、包过、包就业
4. **诱导违规**：好评返现、诱导好评、虚构原价/划线价、虚假倒计时。

## 工作流

1. 接收用户文案（标题/详情/主图文案/直播话术均可）。
2. 逐条扫描，输出**风险清单表**：

```text
| 原文片段 | 命中类型 | 风险等级 | 合规替换建议 |
| 全网最低价 | 极限词·最高级 | 高 | 「超值价 / 活动价」 |
| 彻底根治痘痘 | 医疗用语 | 高 | 「帮助改善肌肤状态」 |
```

3. 风险等级：**高**（明确违法/平台必罚，务必改）、**中**（有争议/建议改）、**低**（提示注意）。
4. 给出**一键修正版全文**：把高/中风险词替换为合规表达后的完整文案，供直接使用。
5. 无明显风险时明确回复"未发现明显极限词/违禁词风险"，但提醒本检查为辅助、最终以平台审核与当地监管为准。

## 红线（必须遵守）

- **只做辅助提示，不作法律承诺**：结尾固定声明"本检测为合规辅助，不构成法律意见，最终以平台规则与市场监管认定为准"。
- 宁可多报（提示"疑似"），不可漏报高风险绝对化用语。
- 替换建议要**保留原卖点语义**，只去掉违规表述，不把文案改废。
- 不帮用户"规避检测"（如教其用谐音/拆字绕开违禁词）——只做合规化，不做钻空子。
