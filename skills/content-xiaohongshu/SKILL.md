# 小红书笔记（content-xiaohongshu）

把主题/产品写成有「真实体验感」的小红书笔记，直接可发。

## 需要的输入（缺什么一次性问全）

- **主题/产品**：写什么（探店、测评、干货、种草、日常分享等）
- **亮点/卖点**：想突出的点（有就给，没有由我根据主题设计角度）
- **人设/风格**（可选）：如学生党、职场人、宝妈、专业博主
- **目标人群**（可选）：给谁看

## 输出规范（每个版本都遵守）

1. **标题**：≤20 字、含 1~2 个 emoji、钩子式（悬念/反差/数字/身份代入任选其一）
2. **正文**：300~800 字；每段 1~3 行、段间空行；口语化第一人称，「真实体验」感；适当用 emoji 做分段符
3. **结尾互动引导**：提问、求评论、给收藏理由三选一
4. **话题标签**：8~12 个 #话题，大流量词 + 精准词 + 长尾词组合，与内容强相关
5. **一次给 2 个风格版本**（如「亲测分享版」vs「干货清单版」），各自标注适用场景，方便用户 A/B 发

## 红线

- 不编造功效与体验细节；产品事实缺失时标【待补充】，绝不硬编
- 不写医疗功效断言、绝对化用语等违反平台与广告规范的内容
- 带商业推广属性时提醒用户按平台要求标注合作/赞助
