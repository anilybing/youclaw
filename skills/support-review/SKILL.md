# 评价/口碑回复（support-review）

给店铺/商家的评价区写**得体的官方回复**：好评借势引导复购，中差评把危机变口碑。回复既是给当事顾客看，也是给潜在买家看的"公开门面"，所以永远专业、有温度、不对线。

## 评价类型与回复策略

| 类型 | 目标 | 回复结构 |
| --- | --- | --- |
| 好评 | 致谢+沉淀口碑+引导复购 | 真诚致谢 → 呼应其提到的亮点 → 轻引导（关注/复购/新品） |
| 中评 | 挽回体验+推动改进 | 感谢反馈 → 认可不足 → 说明改进 → 邀请再体验 |
| 差评 | 先止损再解决+挽回形象 | 真诚道歉 → 共情 → 给解决方案 → 适度补偿话术 → 邀请私信 |

## 需要的输入（缺什么一次性问全）

- **评价原文**（及星级）：一条或一批都行。
- **平台**：淘宝/天猫、拼多多、京东、抖音、小红书、美团/大众点评、亚马逊等（影响能否放联系方式、字数与风格）。
- **可用底牌**：能否补偿、补偿形式（补发/优惠券/退差价）、可引导的动作（关注店铺/加私域/看新品）——**无授权不写具体补偿金额**。

## 工作流

1. 判断评价类型（好/中/差）与核心槽点/亮点，逐条对应回复。
2. 按类型结构组织回复，语气**真诚、具体、不模板化**：
   - **好评**：呼应顾客提到的具体点（"很高兴您喜欢这款的手感"），再自然引导复购/关注，不硬广。
   - **中差评**：**先道歉再解释**，绝不辩解在前；针对具体问题给可执行方案，把补偿写成话术占位符（如「为您补发/送上[补偿]」），并**邀请私信/联系客服**把纠纷引导到私下解决。
3. 差评额外给**两版**：一版公开回复（对外、克制、专业），一版建议私信话术（对内、可谈具体补偿），并提示"补偿细节在私信谈，公开回复不承诺具体金额"。
4. 批量评价时输出表格：| 评价摘要 | 星级/类型 | 建议回复 |，好差评混排也逐条给。
5. 遵守平台规范（见红线），涉及不能公开的信息（联系方式/外链）时改为"私信我们""联系在线客服"。
6. 需要把回复整理成台账交付时调用 `office-excel`；反复出现的差评槽点，提示可用 `support-ticket` 归因、`support-faq` 沉淀答案。落盘到「客服产出」目录。

## 红线（必须遵守）

- **不与顾客对线**：无论评价多不公，都不争辩、不指责、不阴阳怪气、不质疑顾客动机；对外统一先担责再解决。
- **不诱导删评/改评、不返现换好评**：不写"删了差评就补偿""改成好评返现"等诱导话术——多数平台明令禁止，属违规。
- **补偿不越权**：公开回复不承诺具体赔付金额/时效，具体补偿引导到私信并在授权范围内进行。
- **遵守各平台评价回复规范**：不同平台对放联系方式、外链、二维码、字数限制不同，不确定时按"不留私人联系方式、引导站内私信"的稳妥口径，并提示以平台规则为准。
- **不虚构与不透露隐私**：不编造未发生的处理结果，不在公开回复里暴露顾客订单号/手机号/地址等隐私。
- 保持真诚具体，避免千篇一律的复制粘贴式回复（平台可能判"刷屏/无效回复"）。
