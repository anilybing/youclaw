# 简历筛选（hr-resume-screen）

对照岗位 JD，对用户粘贴的一份或多份简历做结构化评估、打分、排序，并给出面试建议与追问点。

## 需要的输入

- **JD 或岗位要求**：没有 JD 时先问核心要求（必备技能、经验年限、关键职责）；仍不清晰可先用 hr-jd 技能澄清岗位画像
- **简历**：一份或多份（直接粘贴文本；附件 .pdf/.docx 用内置 parse_document 工具先解析）

## 评估维度（四维打分，各 1~5 分）

| 维度 | 看什么 |
| --- | --- |
| 技能匹配 | 岗位必备技能/工具/证书的覆盖度 |
| 经验匹配 | 相关经历的深度、项目规模、业绩结果 |
| 稳定性 | 任职时长与连续性（**只看客观时长/频率，不臆测原因**） |
| 学历/专业 | 与岗位相关的专业背景（**仅作参考维度，不设院校歧视**） |

## 输出格式

1. **单份评估卡**（每份简历一张）：
   - 候选人标识（姓名或"简历 1"）
   - 四维打分 + 总分/加权分
   - 亮点（2~3 条）与顾虑（2~3 条），均需引用简历依据
   - 建议：**通过面试 / 待定 / 淘汰** + 一句话理由
   - 面试追问点：3~5 条，针对该简历的空白或存疑处
2. **多份对比**（≥2 份时）：按总分排序的表格（候选人 / 各维度分 / 总分 / 建议），并给一句话总体建议（优先面谁）。

## 工作流

1. 先确认 JD/核心要求，再逐份对照评估。
2. 每个打分给依据，避免"感觉不错"这类无依据结论。
3. 简历信息不足以判断某维度时标"信息不足"，转化为面试追问点，**不硬编分数**。
4. 用户要把评估结果落表交付时，调用 office-excel 技能生成打分表。

## 红线（反歧视合规 —— 必须遵守）

- **只基于岗位相关能力评估**。严禁依据**性别、年龄、婚育状况、地域/户籍、民族、宗教、健康、外貌、院校出身**做评分或建议。
- 简历中若出现上述**与岗位无关的信息**（如婚育、籍贯、照片、年龄），**评估时一律忽略**，并提示用户"这些属无关信息，已按合规不纳入评估"。
- 稳定性维度只描述客观任职时长/频率，不对跳槽动机、家庭状况做主观揣测。
- 不确定的经历不脑补；有疑点转化为面试追问点，而非直接据此淘汰。
