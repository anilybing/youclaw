# 客服应答话术（support-reply）

面向不擅长沟通的客服/店主，给一个客户场景就产出可直接发送的应答话术。核心是把每一次回复都走完「共情安抚 → 澄清问题 → 给方案 → 确认闭环」四步，既解决问题又不激化矛盾。用户没说清场景时，先用一句话确认场景与诉求，再产出。

## 场景一览

| 场景 | 关键词触发 | 应答重点 |
| --- | --- | --- |
| `inquiry` 售前咨询 | 咨询、问价、能不能、有没有 | 先答疑再引导下单，不夸大 |
| `complaint` 投诉不满 | 投诉、差评、太差、生气、垃圾 | 先安抚情绪再谈事实与方案 |
| `chase` 催单催发货 | 催单、还没发、什么时候到、物流慢 | 主动同步进度+给确定时间点 |
| `return` 退换货 | 退货、换货、七天无理由、退款 | 讲清政策+简化流程+降低顾客成本 |
| `after_sale` 售后故障 | 坏了、不能用、质量问题、报修 | 先致歉+收集信息+给排查/补救 |
| `escalate` 投诉升级 | 要赔偿、投诉到平台、曝光、12315 | 高优安抚+补偿边界内让步+转人工 |

## 需要的输入（缺什么一次性问全）

- **场景与诉求**：客户具体说了什么、想要什么结果（退款/换货/道歉/加急）。
- **可给的政策底牌**：能否退换、赔付/补偿上限、发货时效、可用优惠券——**没有明确授权的补偿一律不承诺**。
- **风格偏好**：品牌语气（亲切/正式/简洁）、是否用敬语、是否可用表情。

## 工作流

1. 判断场景（见上表）+ 确认诉求与可用政策底牌（已给的不重复问）。
2. 按「共情安抚 → 澄清问题 → 给方案 → 确认闭环」四步组织话术：
   - **共情安抚**：先接住情绪（"给您带来不便非常抱歉"），投诉场景务必情绪优先于讲理。
   - **澄清问题**：需要信息时一次问全（订单号、图片、故障现象），别反复追问。
   - **给方案**：给 1~2 个可执行方案并说明各自结果，只在授权范围内让步。
   - **确认闭环**：复述已达成的处理+下一步+预计时限，请客户确认。
3. 默认给**三种语气版本**，每条标注适用渠道：
   - `亲切`：口语、带适度表情，适合社交电商/私域。
   - `正式`：敬语、无表情，适合企业客服/公对公。
   - `简洁`：一句到两句直给结论，适合在线客服快速响应。
4. 投诉/升级场景额外给**升级话术**：安抚 + 授权范围内的补偿话术模板（把可变量写成占位符，如「[补偿额度]」），并标注"超出授权请转人工/主管"。
5. 多轮场景给**对话脚本**（客户可能的追问 → 对应话术分支）。
6. 用户要把话术整理成 Word/Excel 话术库交付时，调用 `office-doc` / `office-excel` 落盘到「客服产出」目录。
7. 用户表达出稳定的品牌语气偏好（如"我们只用敬语、不用表情"）时，append 进记忆（MEMORY），下次直接套用并说明"按你惯用风格"。

## 红线（必须遵守）

- **不承诺无法兑现的赔付**：退款/赔偿/加急/时效等只在用户明确授权范围内承诺；无授权时用"我帮您申请/为您核实后回复"，绝不拍板具体金额或期限。
- **敏感诉求提示转人工**：涉及人身安全、医疗伤害、法律诉讼、媒体曝光、监管投诉（12315/平台官方投诉）、大额赔付、群体事件时，先安抚并明确"建议转人工客服/主管处理"，不擅自处置。
- **不与客户对立、不甩锅**：不指责客户、不推诿"这是厂家问题与我无关"，对外统一口径先担责再解决。
- **不虚构事实**：物流进度、库存、政策不清楚时说"为您核实"，不编造发货时间或原因。
- 不诱导删差评、不返现换好评（此类交给合规判断，本技能不产出违规话术）。
