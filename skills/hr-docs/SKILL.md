# 人事文档（hr-docs）

生成常用人事文档的要点清单与可套用模板，帮 HR 快速起草制度与流程文件。

## 覆盖的文档类型

| 类型 | 产出 |
| --- | --- |
| 劳动合同关键条款清单 | 必备条款逐项清单 + 每项要点/常见坑（非合同全文） |
| 员工手册章节大纲 | 章节结构 + 每章要点（考勤/薪酬/假期/奖惩/保密等） |
| 入职流程与清单 | 入职步骤 + 材料/账号/设备/培训 交接清单 |
| 离职流程与交接清单 | 离职步骤 + 工作交接/资产回收/权限注销/结算 清单 |
| 通知模板 | 录用通知（Offer）/ 转正通知 / 调岗通知 等 |

## 需要的输入

- **要哪类文档**（见上表）
- **公司/岗位背景**：行业、规模、是否有特殊制度；缺失按通用模板处理并标注可定制处
- **通知类模板**：员工姓名、岗位、生效日期、薪资/条件等占位信息（可用【】占位符留空）

## 输出格式

- **清单/大纲类**：结构化 Markdown，分级标题 + 要点，关键条款给一句话说明
- **模板类**：可直接套用的文本，变量用【方括号占位符】（如【员工姓名】【入职日期】【月薪】），并在末尾列出需替换的占位符清单
- 用户要 Word/Excel 交付时，分别调用 office-doc / office-excel 技能落盘

## 工作流

1. 确认文档类型与公司背景。
2. 产出要点清单或模板；模板保留占位符，方便用户替换。
3. 主动提示哪些条款/数字需按公司实际与当地法规填写。

## 红线（法律免责 —— 必须遵守）

- **不构成法律意见**：涉及劳动法/社保/个税/竞业/工时等**具体条款、数额、期限**时，一律提示：**「请以当地现行劳动法规与专业法务/律师意见为准」**，模板仅供参考。
- 不编造具体法条编号或数值（如赔偿倍数、试用期上限、竞业补偿比例）；不确定处标【以当地法规为准】。
- 不生成规避法律、损害劳动者合法权益的条款（如违法约定的罚款、超时试用期、无效竞业限制）。
- 涉及员工个人信息的模板，提示做好隐私保护与合规存储。
