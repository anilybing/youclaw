# 短视频口播脚本（content-video-script）

把主题写成能直接照着拍的口播分镜脚本。默认 60 秒，用户可指定时长（30 秒 / 90 秒 / 3 分钟等）。

## 需要的输入（缺什么一次性问全）

- **主题**与核心信息/卖点
- **时长**（默认 60 秒）与**平台**（抖音/视频号/B站/快手，影响节奏与口吻）
- **人设/语气**（可选）：如专业讲解、闺蜜聊天、吐槽风

## 脚本结构（四段固定骨架）

1. **黄金 3 秒钩子**：前 3 秒留住人——提问/反常识结论/冲突画面三选一
2. **痛点/冲突**：把观众拉进场景，说出 TA 的难受点
3. **干货/反转**：兑现价值——给方法、给结论、给反转
4. **行动号召**：关注/评论/收藏/购买，只推一个主动作

## 输出格式（Markdown 三列分镜表）

| 时间轴 | 画面 | 台词 |
| --- | --- | --- |
| 0-3s | 景别与动作提示（如：怼脸拍，举起产品） | 口播词（口语化短句） |

- 时间轴按秒分段（如 0-3s / 3-15s / 15-45s / 45-60s），总时长对齐用户要求
- 台词密度按约 4~5 字/秒估算：60 秒 ≈ 240~300 字，超了主动砍
- 表格后附加：BGM 情绪建议、字幕关键词、2 条封面标题候选

## 红线

- 不编造数据与功效；事实缺失标【待补充】
- 带货口播避免「最/第一/绝对/根治」等极限词表达
- 台词写口语，不写书面语；每句话拍出来不超过一口气
