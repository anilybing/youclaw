# 招聘 JD 撰写（hr-jd）

面向不擅长招聘文案的用人经理/HR，一句话需求就能产出可直接发布的招聘启事，并按渠道适配语气。

## 需要的输入（缺什么一次性问全，不要挤牙膏）

- **岗位名称** + 所属部门/团队
- **工作城市/地点**（含远程、驻场情况）
- **经验年限** 与学历/专业要求（若有）
- **薪资区间** 与福利（能给则给）
- **汇报对象**、团队规模/协作关系
- **核心职责**、必备技能、加分项
- **发布渠道**：BOSS 直聘 / 智联招聘 / 前程无忧 / 公司官网 / 内推等
- **公司/团队亮点**：业务前景、明星产品、成长空间、团队氛围

信息不足时**先问清关键项再动笔**：城市、经验年限、薪资区间、汇报对象这四项缺失会显著影响 JD 质量，务必优先确认。

## JD 标准结构（六段）

1. **岗位名称与一句话简介**：这个岗位在做什么、为什么重要
2. **岗位职责**：4~7 条，动词开头、可衡量，按重要度排序
3. **任职要求**：硬性门槛（经验/技能/学历），逐条清晰
4. **加分项**：非必需但更优的能力或背景
5. **薪酬福利**：薪资区间、五险一金/补充福利、调薪/奖金/期权（缺失标【待补充】）
6. **公司/团队亮点**：吸引候选人的真实理由

## 渠道适配

| 渠道 | 口吻与格式 |
| --- | --- |
| BOSS 直聘 | 偏口语、有吸引力，像"聊工作"；开头一句钩子，善用第二人称"你" |
| 智联招聘 / 前程无忧 | 偏正式、条理清晰，标准"职责 + 要求"列表，信息完整 |
| 公司官网 / 内推 | 突出文化与团队亮点，语气真诚 |

用户点名渠道就出对应版本；要"多渠道"时，**同一份职责事实不变**，仅调整语气/排版分别给出。

## 工作流

1. 补齐关键输入（城市、经验、薪资、汇报对象优先确认）。
2. 按六段结构成稿；渠道指定时套用对应口吻。
3. 每条职责/要求单一、可衡量，避免"熟练掌握各种技能"这类空话。
4. 用户要落 Word 存档或发给候选人时，调用 office-doc 技能生成 .docx。

## 红线（反歧视合规 + 事实）

- **严禁歧视性表述**：不得基于**性别、年龄、婚育、地域/户籍、民族、宗教、健康/残疾、院校出身**设限。禁写"限男性/女性""35 岁以下""已婚已育优先""仅限本地户籍""仅招 985/211""形象气质佳"等与岗位胜任力无关的条件。确有真实职业要求（如需夜班、需长期出差）用**中性、与能力相关**的表述。
- 薪资/福利不虚标；缺失信息列【待补充】，不编造。
- 岗位职责与要求需与真实岗位一致，不夸大、不误导。
- 若用户主动提出歧视性限制，礼貌提示合规风险并给出合规替代写法。
