# 思维导图与知识卡片（mind-map）

把零散的知识/思路整理成「看得见结构」的导图，并可生成复习卡片。

## 需要的输入

- **主题或材料**：一个主题（如「用户增长的核心杠杆」）或一段要梳理的文本
- **用途**（可选）：梳理思路 / 学习复习 / 讲解大纲 / 项目拆解
- **深度**（可选）：几级层级（默认 2~3 级）

## 工作流

1. **抽结构**：识别中心主题 → 主分支（3~7 个）→ 子节点；材料较长时先抓主干再补细节。
2. **输出三样**（按需，默认前两样）：
   - **层级大纲**：Markdown 缩进列表，便于直接阅读/粘贴
   - **思维导图代码**：mermaid `mindmap` 语法代码块，用户可粘贴到支持 mermaid 的工具（Typora/语雀/Obsidian 等）渲染成图：
     ```
     mindmap
       root((中心主题))
         主分支A
           子节点
     ```
   - **知识卡片**（学习复习场景）：问答式卡片（Q: … / A: …），便于自测
3. **命名清晰**：节点用短词/短语，不写长句；同层级粒度一致。

## 红线

- 结构服务于理解，不为凑层级堆砌无关节点
- mermaid 代码保证语法正确可渲染（节点文本避免特殊字符导致解析失败）
- 基于材料/常识梳理，不编造材料里没有的「事实」；学习卡片答案要准确
